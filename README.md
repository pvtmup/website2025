# LORE

**Everyone's a main character. Only some become legend.**

LORE — это не AI-чат и не соцсеть. Это **живой сериал, в котором ты — главный герой, ИИ — режиссёр (showrunner), а друзья — реальный каст и первые зрители.** ИI круглосуточно пишет эпизоды про тебя и твоё окружение, ты делаешь выборы, меняющие сюжет, лучшие моменты превращаются в клипы и набирают фанатов. Слава внутри мира = реальная социальная валюта.

Это рабочий интерактивный прототип концепции (formerly «новый формат взаимодействия человека и ИИ»).

## Что внутри прототипа

- 🎬 **Кинематографичный онбординг** — трейлер «ты — главный герой», выбор имени, архетипа (6 шт.) и мира (5 шт.).
- 🖼️ **Процедурные постеры эпизодов** (`js/art.js`) — каждый эпизод получает уникальный SVG-арт (skyline/горы/сцена/космос + силуэт, частицы, виньетка, зерно), детерминированно генерируемый из заголовка.
- ✍️ **AI-Showrunner движок** (`js/engine.js`) — генерирует уникальные эпизоды: cold-open по архетипу, бит по отношениям с со-актёром, клиффхэнгер и выборы, влияющие на сюжет.
- ✨ **Живая генерация через Claude** (`js/ai.js`, опционально) — добавь Anthropic API-ключ в Настройках → эпизоды пишет **Claude** вживую. Любая ошибка/офлайн → бесшовный фолбэк на встроенный движок.
- 🎞️ **Сезоны и финалы** — эпизоды группируются в сезоны по 6, каждый 6-й — премиальный SEASON FINALE.
- 👁 **Виральные метрики** — каждый эпизод набирает просмотры/лайки/фанатов, бывают «вирусные» прорывы (🚀).
- 💬 **Реакции фанатов** — под каждым сыгранным эпизодом авто-генерятся комменты/шипперы/шок-реакции (social proof).
- ⇪ **Экспорт клипа** (`js/share.js`) — рендер эпизода в 9:16 PNG-карточку (Canvas) с вотермаркой LORE → нативный share или скачивание. Виральная петля «постни → притяни фанов» сделана осязаемой.
- ✍️ **Писательский зал** — ежедневное голосование за повороты сюжета (коллективный сторителлинг = retention-петля), даёт influence-бонус.
- 🤝 **Каст (со-актёры)** — добавляешь друзей с типом отношений (Ally / Rival / Love / Secret); драма строится вокруг них. Заложена логика double-opt-in (без дипфейков).
- ✦ **Trending-лента** — твои клипы вперемешку с «миром», у каждого свой постер.
- ★ **Прогрессия и статусы** — лестница из 5 тиров (Nameless → Character w/ Lore → Local Star → Legend of the Season → CANON), 10 достижений, дневной стрик.
- 🔊 **Звук** (`js/audio.js`) — кинематографичные WebAudio-микровзаимодействия (без ассетов), тумблер в Настройках.
- 📲 **PWA** — `manifest.webmanifest` + `sw.js`: устанавливается как приложение, работает офлайн.
- 🌙 **Персистентный мир** — состояние в `localStorage`; пока тебя нет, мир «живёт» и накапливает события («While you were gone…»).
- 💜 **Монетизация** — LORE+ (подписка) и Productions, продаётся *слава и самовыражение*, а не одиночество.

## Запуск

Никакой сборки и зависимостей. Любой статический сервер:

```bash
python3 -m http.server 8099
# открой http://localhost:8099
```

Или просто открой `index.html` в браузере.

## Структура

```
index.html              каркас + phone-frame + PWA/SW регистрация
manifest.webmanifest    PWA-манифест (installable)
sw.js                   service worker (offline app-shell)
assets/icon.svg         иконка приложения
css/styles.css          дизайн-система (cinematic dark, vertical-first)
js/data.js              «писательская комната»: архетипы, миры, нарративная грамматика, реакции, промпты
js/art.js               процедурный генератор постеров (SVG, детерминированный)
js/engine.js            AI-showrunner: эпизоды, сезоны/финалы, виральность, реакции, писательский зал
js/ai.js                опциональная живая генерация через Claude API (+ фолбэк)
js/audio.js             WebAudio микро-FX
js/share.js             экспорт клипа в PNG-карточку (Canvas)
js/store.js             состояние + localStorage + достижения
js/ui.js                вьюхи (возвращают HTML)
js/app.js               роутинг, онбординг, игровой цикл, события
CONCEPT.md              полный продуктовый/стратегический разбор (рынок, 30 идей, разнос Sequoia, финал)
```

## Включить живую AI-генерацию (Claude)

1. Открой **You → ⚙ Settings & AI**.
2. Вставь Anthropic API-ключ (`sk-ant-...`), нажми **Save key** → **Test**.
3. Включи тумблер **Use Live AI**. Теперь каждый новый эпизод пишет Claude.

Ключ хранится только в `localStorage` твоего браузера и шлётся напрямую в `api.anthropic.com` (direct browser access). Без ключа/при ошибке всё работает на встроенном движке.

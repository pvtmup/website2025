# LORE

**Everyone's a main character. Only some become legend.**

LORE — это не AI-чат и не соцсеть. Это **живой сериал, в котором ты — главный герой, ИИ — режиссёр (showrunner), а друзья — реальный каст и первые зрители.** ИI круглосуточно пишет эпизоды про тебя и твоё окружение, ты делаешь выборы, меняющие сюжет, лучшие моменты превращаются в клипы и набирают фанатов. Слава внутри мира = реальная социальная валюта.

Это рабочий интерактивный прототип концепции (formerly «новый формат взаимодействия человека и ИИ»).

## Что внутри прототипа

- 🎬 **Кинематографичный онбординг** — трейлер «ты — главный герой», выбор имени, архетипа (6 шт.) и мира (5 шт.).
- ✍️ **AI-Showrunner движок** (`js/engine.js`) — грамматически генерирует уникальные эпизоды: cold-open по архетипу, бит по отношениям с со-актёром, клиффхэнгер и выборы, влияющие на сюжет.
- 👁 **Виральные метрики** — каждый эпизод набирает просмотры/лайки/фанатов, бывают «вирусные» прорывы (🚀).
- 🤝 **Каст (со-актёры)** — добавляешь друзей с типом отношений (Ally / Rival / Love / Secret); драма строится вокруг них. Заложена логика double-opt-in (без дипфейков).
- ✦ **Trending-лента** — твои клипы вперемешку с «миром».
- ★ **Прогрессия и статусы** — лестница из 5 тиров (Nameless → Character w/ Lore → Local Star → Legend of the Season → CANON), 10 достижений, дневной стрик.
- 🌙 **Персистентный мир** — состояние хранится в `localStorage`; пока тебя нет, мир «живёт» и накапливает события («While you were gone…»).
- 💜 **Монетизация** — LORE+ (подписка) и Productions, продаётся *слава и самовыражение*, а не одиночество.

## Запуск

Никакой сборки и зависимостей. Любой статический сервер:

```bash
python3 -m http.server 8099
# открой http://localhost:8099
```

Или просто открой `index.html` в браузере.

## Структура

```
index.html        каркас + phone-frame
css/styles.css    дизайн-система (cinematic dark, vertical-first)
js/data.js        «писательская комната»: архетипы, миры, нарративная грамматика
js/engine.js      AI-showrunner: генерация эпизодов, скоринг виральности, мир «между визитами»
js/store.js       состояние + localStorage + достижения
js/ui.js          вьюхи (возвращают HTML)
js/app.js         роутинг, онбординг, игровой цикл, события
CONCEPT.md        полный продуктовый/стратегический разбор (анализ рынка, 30 идей, разнос Sequoia, финал)
```

## Дисклеймер

Это концепт-билд. «AI-генерация» здесь — детерминированный нарративный движок на грамматиках (демонстрирует UX и петли без затрат на LLM-инференс). В продакшене showrunner — это LLM + стилизованный анимационный рендер; см. `CONCEPT.md`.

# СТЭК — концепт (соц-казуалка из deep-research)

> Реализация рекомендаций отчёта: **сверх-простое гипер-казуальное ядро + богатый соц-слой**, mobile-first, вирусность через шеринг и реферал, монетизация косметикой без P2W.

## Идея в одну строку
**Башня в один тап.** Роняешь блоки друг на друга, промахнулся — край отрезается, башня сужается. Один и тот же «сид» у всех в ежедневном челлендже и в дуэли с другом → честное сравнение и вирусный цикл «побей мой результат».

## Почему именно эта механика (из меню отчёта)
Отчёт предлагал 4 простых механики. Берём **«складывание падающих объектов»** в самой залипательной форме (stack-tower):
- **Мгновенное обучение** — правило одно: тап = поставить блок. Осваивается за 2 секунды.
- **Короткая сессия** + «ещё одна попытка» (как Among Us/hyper-casual).
- **Детерминизм по сиду** — то, чего нет у обычных тетрисов: одинаковая последовательность для всех → дневной лидерборд и async-дуэли как у Wordle.

## Целевая аудитория
Зумеры 13–25, mobile-first (69% играют на телефоне). Казуалы-социализаторы + крафтеры + «зрители-инфлюенсеры». Женская аудитория — через косметику/скины.

## Соц-слой и вирусные механики (ядро ценности)
- **Дневной челлендж** — у всех один сид на сегодня → общий лидерборд, повод заходить каждый день (retention).
- **Дуэль по ссылке** — `?seed=…` отдаёт другу ту же последовательность; «я собрал N, побей» — главный **K-фактор**, шеринг в один тап в TikTok/Telegram.
- **Карточка результата (PNG)** — авто-рендер «мой рекорд + ссылка-вызов» для сторис/чатов.
- **Реферал** — `?ref=…`: монеты обеим сторонам (взаимный бонус → K>1).
- **Лидерборд + стрик** — ранг среди друзей и мира; ежедневный стрик усиливает мотивацию.
- **Косметика как соц-статус** — скины башни, которыми хвастаются в клипах.

## Монетизация (без разрушения вирусности)
- **Косметика** (скины/палитры/эффекты) — меняют только вид, не баланс. Основной доход.
- **Battle Pass / сезон** — трек косметики за игру (повод возвращаться).
- **Rewarded-видео** — опционально: продолжить после проигрыша / x2 монеты (не чаще 1–2/сессию).
- Никакого P2W: сид и физика честные для всех.

## KPI (из отчёта, под этот продукт)
- D1 ~35–40%, D7 ~10–15%, D30 ~5–10%.
- **K-фактор > 1.0** (цель 1.1–1.2) — измеряем через переходы по `?seed`/`?ref`.
- ≥30% органических установок (по дуэлям/шерингу).
- Сессия: «ещё одна попытка» → 6+ забегов за сессию.

## Что в прототипе (MVP) — см. README
Дневной челлендж, бесконечный режим, дуэль по ссылке, монеты, магазин скинов, реферал-инвайт, шеринг-карточка, лидерборд, звук, локализация RU, mobile-first, сочный фидбэк (perfect-комбо, частицы, тряска).

## Риски и снижение (из отчёта)
- **Скучает от простоты** → перфект-комбо, скины, дневной сид, дуэли, события.
- **Модерация/токсичность** → имена/ники фильтруются; ник опционален.
- **Агрессивная монетизация** → только косметика + опц. реклама.
- **Юр./возраст** → без 18+, минимум данных, всё локально на устройстве в прототипе.

# Запуск СТЭК как Telegram Mini App

Игра уже готова к работе внутри Telegram (имя игрока, вибро, шеринг в чаты, дип-линки дуэлей).
Остаётся 5 минут настройки в @BotFather — собственного кода писать не нужно.

## Шаги

1. **Создай бота.** В Telegram открой **@BotFather** → `/newbot` → задай имя и username (например `stack_game_bot`). Получишь токен (нужен для бота; для самой игры не требуется).

2. **Создай Mini App.** В @BotFather → `/newapp` → выбери своего бота:
   - Title: `СТЭК`
   - Short name: `stack` (попадёт в ссылку)
   - Description / иконка — на вкус
   - **Web App URL:** `https://pvtmup.github.io/website2025/stack/`
   - Получишь ссылку вида **`https://t.me/stack_game_bot/stack`**

3. **Впиши ссылку в игру.** Открой `stack/js/tg.js` и поставь:
   ```js
   const APP_URL = "https://t.me/stack_game_bot/stack";
   ```
   Закоммить/запушь (Pages передеплоится). Теперь дуэли и инвайты открываются **внутри** Telegram.

4. **(Опц.) Кнопка-меню.** @BotFather → `/setmenubutton` → выбери бота → задай текст «Играть» и тот же URL. Игра будет открываться по кнопке в чате с ботом.

5. **Готово.** Открой `https://t.me/stack_game_bot/stack` на телефоне в Telegram.

## Что уже работает в Telegram
- **Авто-имя игрока** из аккаунта Telegram (попадает в таблицу).
- **Тактильная отдача** (вибро) на установку блока, перфект, рекорд, проигрыш.
- **Шеринг в чаты** — нативный выбор чата Telegram (кнопки «Бросить вызов» и «Позвать»).
- **Дип-линки дуэлей:** `?startapp=d<seed>s<score>` — другу открывается **та же башня** и твоя цель. Реферал: `?startapp=ref` (+150 🪙 обеим сторонам).
- **Fullscreen + защита от случайного закрытия** свайпом, тёмная шапка под игру.

## Технические заметки
- Нужен **HTTPS** — GitHub Pages его даёт из коробки.
- Telegram SDK подключён в `index.html` (`telegram-web-app.js`).
- Вне Telegram (обычный браузер) всё работает с фолбэком: дуэль через `?seed=&s=`, шеринг через системный `navigator.share` / копирование ссылки / PNG-карточку.
- Для офлайна/иконки на главном экране позже можно добавить отдельный PWA-манифест и service worker для `/stack/`.

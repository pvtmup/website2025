# СТЭК 🧱 — башня в один тап

Гипер-казуальная социальная игра (реализация deep-research концепта, см. `CONCEPT.md`).
Ставь падающие блоки в один тап, держи башню, бей рекорд. Один **сид** у всех в дневном
челлендже и в дуэли по ссылке → честное сравнение и вирусный цикл «побей мой результат».

## Возможности (MVP)
- 🎮 **Ядро в один тап** — canvas-движок: точное попадание = **perfect-комбо** + башня шире; промах режет край. Скорость растёт.
- 📅 **Дневной челлендж** — у всех один сид на день → общий лидерборд, повод заходить каждый день.
- ⚔️ **Дуэль по ссылке** — `?seed=…&s=…`: другу выпадает та же башня и твоя цель. Главный K-фактор.
- ⇪ **Карточка результата (PNG)** + ссылка-вызов (нативный share / копирование).
- 📨 **Реферал** — `?ref=…` даёт монеты (взаимный бонус).
- 🎨 **Магазин скинов** — палитры башни, **только косметика, без P2W**. Монеты за высоту/перфекты.
- 📊 **Таблица** — дневной рейтинг (+ твой ранг), 🔥 стрик.
- 🔊 Звук (WebAudio, без ассетов), 🇷🇺 локализация, mobile-first, сочный фидбэк (частицы, тряска, комбо).

## Запуск
Никакой сборки. Любой статический сервер из этой папки:
```bash
python3 -m http.server 8080   # → http://localhost:8080/stack/  (из корня репо)
```
или открыть `stack/index.html`. Управление: **тап по полю** (или Пробел) ставит блок.

## Структура
```
index.html        каркас (canvas + overlay + hud)
css/styles.css    стили (mobile-first, тёмно, сочно)
js/rng.js         детерминированный ГПСЧ (сид) + сид дня
js/skins.js       косметические палитры башни
js/game.js        игровой движок (canvas, физика, нарезка, частицы)
js/store.js       состояние (монеты, рекорды, скины, стрик) — localStorage
js/audio.js       WebAudio FX
js/share.js       ссылка-вызов по сиду + PNG-карточка
js/ui.js          экраны (меню, гейм-овер, магазин, таблица)
js/app.js         оркестрация (URL-сид/реферал, режимы, ввод, монеты)
CONCEPT.md        концепт + соц-слой + монетизация + KPI
```

LORE (другой продукт) живёт в корне репозитория и не затронут.

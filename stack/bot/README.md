# СТЭК — бот и напоминания

Mini App сам по себе **не может** слать пуши — нужен бот-сервер. Здесь готовый стартер
без зависимостей (Node 18+, использует встроенный `fetch`).

> ⚠️ Это серверная часть. GitHub Pages её не запускает — нужен любой хост (VPS,
> Railway, Render, домашний ПК с `pm2`/`systemd`, и т.п.).

## Что делает
- `bot.js` — long-polling: на `/start` регистрирует пользователя в `users.json` и
  отправляет кнопку **🎮 Играть** (открывает Mini App). Это и есть «база» для напоминаний.
- `remind.js` — рассылает напоминание всем, кто запускал бота (стрик/задания/сезон/рекорд).
  Запускается по расписанию (cron) раз в день.

## Настройка (5 минут)
1. Создай бота в **@BotFather** → получишь `BOT_TOKEN`.
2. (Mini App уже настроен — см. `../TELEGRAM.md`.)
3. Запусти приёмник `/start`:
   ```bash
   BOT_TOKEN=123:ABC node bot.js
   ```
   (держи процесс живым: `pm2 start bot.js` / `systemd` / хостинг).
4. Поставь ежедневную рассылку, например в 18:00:
   ```cron
   0 18 * * *  BOT_TOKEN=123:ABC node /полный/путь/stack/bot/remind.js
   ```

## Переменные окружения
- `BOT_TOKEN` — токен бота (обязательно).
- `WEBAPP_URL` — URL Mini App (по умолчанию `https://pvtmup.github.io/website2025/stack/`).

## Ограничения и заметки
- Напоминание можно слать только тем, кто **сам нажал /start** у бота (правила Telegram).
- Текст общий (бот не знает прогресс игрока — он в CloudStorage на устройстве).
  Если захочешь персональные напоминания «твой стрик сгорит» — нужно синхронизировать
  стрик на сервер (отправлять из Mini App через `sendData`/бэкенд). Это следующий шаг.
- Не спамь: 1 напоминание в день максимум, иначе отписки/баны.
